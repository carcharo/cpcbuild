# Install the tools

CPCBuild compiles your BASIC with the Boriel BASIC compiler. Studio can download it for you.

Choose **Download Tools**. It fetches the compiler (with `zxbasm` and `mkdsk`) and, if you like, the Arkos Tracker command-line tools used to convert music. Each download is checked against a known checksum before it is used.

You can skip this step if your project is inside a CPCBuild SDK folder (Studio finds it by itself), or point `cpcbuild.sdk.path` at one. A zxbasic checkout goes in `cpcbuild.zxbc.cwd`.
